# Chapter 8 Lab: BigQuery ML vs Vertex AI for Data-Driven ML

**Estimated time:** 20 minutes

## Exercise

Design walkthrough: build a BigQuery ML logistic regression model directly on a BigQuery table for churn prediction, then design when the same team would instead hand off to Vertex AI Pipelines for a custom deep-learning model with a shared Feature Store

## Key takeaway

The exam tests the BQML vs Vertex AI decision by team skillset, model complexity, and whether reusable feature serving across models is required.
