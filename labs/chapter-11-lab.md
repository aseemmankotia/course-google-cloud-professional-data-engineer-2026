# Chapter 11 Lab: Security and Compliance for Data Pipelines

**Estimated time:** 25 minutes

## Exercise

Design walkthrough: design column-level security and dynamic data masking on a BigQuery table containing PII, configure a VPC Service Control perimeter around BigQuery and Cloud Storage, and scope a Cloud DLP job to de-identify SSNs before loading to a shared dataset

## Key takeaway

Security questions test matching the correct control layer (IAM, VPC-SC, CMEK, column/row-level security, DLP) to the specific threat described in the scenario.
