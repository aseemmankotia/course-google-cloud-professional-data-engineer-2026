# Chapter 2 Lab: Selecting Transformation Tools and Designing for Governance

**Estimated time:** 20 minutes

## Exercise

Design walkthrough: given four transformation scenarios (existing Spark jobs, new streaming pipeline, GUI-based ETL for non-engineers, SQL-only analytics team), select and justify Dataflow, Dataproc, Data Fusion, or Dataform for each

## Key takeaway

Transformation-tool questions test matching the team's skillset and source format (code, GUI, or SQL) to Dataproc, Data Fusion, or Dataform — Dataflow is reserved for new Beam-native streaming/batch pipelines.
