# Chapter 7 Lab: Bigtable, Spanner, Cloud SQL, and Cloud Storage

**Estimated time:** 25 minutes

## Exercise

Design walkthrough: design a Bigtable row key for IoT sensor time-series data avoiding hotspotting, and choose Cloud Storage lifecycle rules (Standard to Nearline to Coldline to Archive) for a 7-year retention regulatory dataset

## Key takeaway

Bigtable and Cloud Storage questions test whether you match row-key/lifecycle design to the actual access pattern rather than defaulting to more compute or a different service entirely.
