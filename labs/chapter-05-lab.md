# Chapter 5 Lab: Data Fusion, Dataform, and Orchestration with Cloud Composer

**Estimated time:** 25 minutes

## Exercise

Design walkthrough: wire a Cloud Composer DAG that triggers a Data Fusion pipeline, waits for completion, then runs a Dataform transformation, with retries and SLA alerting configured

## Key takeaway

Orchestration questions test whether you keep Composer as the coordination layer and delegate actual transformation work to the purpose-built service.
