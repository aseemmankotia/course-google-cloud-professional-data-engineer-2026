# Chapter 3 Lab: Streaming Ingestion with Pub/Sub and Dataflow

**Estimated time:** 25 minutes

## Exercise

Design walkthrough: architect a Pub/Sub plus Dataflow pipeline for clickstream events with 5-minute session windows, allowed lateness, and a dead-letter topic for malformed messages

## Key takeaway

Streaming exam questions test precise recall of windowing type, watermark/lateness handling, and which layer (Pub/Sub vs Dataflow) provides which delivery guarantee.
